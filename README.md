# وصلني الطائف

واجهة عربية RTL لخدمات المنتجات وطلبات المطاعم والمشاوير في مدينة الطائف. المشروع يحتوي مصدراً كاملاً وواجهة قابلة للمعاينة وملف SQL لـ Supabase، ويُبنى كـ PWA قابلة للتثبيت من Chrome أو متصفح حديث. لا يتضمن المشروع دفعاً إلكترونياً؛ التحصيل نقدي عند التسليم.

## ما في الحزمة

- `client/src/` — صفحات العميل ولوحة المؤسس والمصادقة والدعم.
- `client/src/supabase.js` — إعداد الاتصال العام الذي طلبه المستخدم. يحتوي URL وpublishable/anon key فقط؛ لا يحتوي service-role.
- `supabase/schema.sql` — جداول Postgres وسياسات RLS والدوال المطلوبة وإنشاء bucket `app-images` والقيمة الابتدائية لرسوم التوصيل.
- `supabase/functions/support-assistant/` — دالة دعم اختيارية؛ تتحقق من المستخدم وتستعمل مفتاح نموذج في أسرار Supabase، لا في المتصفح.
- `client/public/manifest.webmanifest` و`client/public/service-worker.js` و`client/public/icons/` — اسم التطبيق وأيقوناته وملفات PWA.
- `.github/workflows/deploy-pages.yml` — بناء ونشر GitHub Pages تلقائياً بعد رفع الملفات إلى مستودع.

## أول إعداد لـ Supabase

1. افتح مشروع Supabase المرتبط بعنوان `https://ubjzxnkrqavwxywhtmof.supabase.co`، ثم افتح **SQL Editor**.
2. انسخ كامل الملف `supabase/schema.sql` وشغّله مرة واحدة. ينشئ الجداول والفهارس والعلاقات وسياسات Row Level Security والدوال، ويجهّز bucket الصور بالاسم `app-images`.
3. من **Authentication → URL Configuration** أضف عنوان GitHub Pages النهائي ضمن **Redirect URLs**، مثل `https://USERNAME.github.io/REPOSITORY/`. أضف عنوان المعاينة أيضاً إذا احتجت اختبار تسجيل الدخول منها. فعّل تأكيد البريد بما يناسبك.
4. سجّل حساباً بالبريد `2008mamms@gmail.com`، ثم أكد الرسالة الواردة إليه. تهيئة SQL تسند دور المؤسس لهذا البريد وحده عند إنشاء الحساب. أي بريد آخر يبدأ كعميل. لا يمكن ترقية مؤسس آخر أو خفض هذا الحساب عبر لوحة التطبيق.
5. صور الأقسام والمنتجات والإعلانات ترفع إلى bucket `app-images`. قراءة الصور عامة لأن صور الكتالوج عامة؛ الرفع والحذف محصوران بالمؤسس أو بإذن إدارة محدد.

المفتاح الموجود في `client/src/supabase.js` هو مفتاح واجهة عام، وليس حماية للبيانات. الأمان الفعلي قائم على RLS وسياسات SQL. لا تضع `service_role` أو أي سر خاص في ملفات JavaScript التي تُرفع إلى GitHub Pages. عند تدوير بيانات الربط غيّر URL أو publishable key في ملف الاتصال ثم أعد البناء.

## معاينة محلية

يتطلب Node.js 20 أو أحدث وpnpm 10.18.0. بعد تنزيل الحزمة:

```sh
pnpm install
pnpm dev:static
```

ثم افتح `http://localhost:3000`. لبناء نسخة GitHub Pages محلياً:

```sh
pnpm build:static
```

الناتج الجاهز للنشر سيكون داخل `dist/public/`. أصول Vite نسبية كي يعمل الموقع تحت مسار المستودع مثل `/REPOSITORY/` على GitHub Pages. قبل تشغيل SQL، يظهر محتوى عرض توضيحي محلي فقط، ولا تُحفظ طلباته في قاعدة بيانات.

## رفع الملفات ونشر GitHub Pages

1. أنشئ مستودع GitHub وارفع إليه جميع ملفات هذه الحزمة، مع مجلد `.github` كما هو.
2. في المستودع افتح **Settings → Pages** واجعل **Build and deployment → Source** هو **GitHub Actions**.
3. ادفع الملفات إلى الفرع `main`، ثم افتح تبويب **Actions** وانتظر نجاح `deploy-pages`. سيظهر رابط الموقع في تفاصيل النشر.
4. أضف هذا الرابط نفسه إلى Supabase Authentication Redirect URLs. صفحات GitHub تستضيف ملفات الواجهة الثابتة فقط؛ بيانات المستخدمين والجداول والمصادقة والملفات تبقى في Supabase.

## تثبيت التطبيق على الهاتف

افتح رابط HTTPS المنشور في Chrome على Android، ثم افتح قائمة المتصفح واختر **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية**. سيظهر الاسم «وصلني الطائف» والرمز الخاص به ويفتح في نافذة مستقلة. هذه PWA مثبّتة من المتصفح؛ ليست تطبيقاً منشوراً في Google Play، ولا يمكن فرض التثبيت من الموقع أو ضمان ظهوره كتطبيق في Google Play. إذا لم يظهر خيار التثبيت، حدّث الصفحة بعد نجاح HTTPS وتأكد من تحميل ملف البيان والأيقونات وService Worker.

يخزن Service Worker قشرة التطبيق والأيقونة فقط. تسجيل الدخول والطلبات تحتاج اتصالاً بالإنترنت، ولا تُخزّن بيانات العملاء أو الطلبات الحساسة دون اتصال.

## الرد الذكي للدعم (اختياري)

الرسائل تصل إلى صندوق المؤسس حتى لو لم تُنشر الدالة. لإضافة رد بالذكاء الاصطناعي، ثبّت Supabase CLI، اربط مجلد المشروع بمشروعك ثم انشر الدالة:

```sh
npx supabase login
npx supabase link --project-ref ubjzxnkrqavwxywhtmof
npx supabase secrets set AI_API_KEY=YOUR_PROVIDER_KEY
npx supabase functions deploy support-assistant
```

مفتاح النموذج سر محفوظ في Supabase Functions، وليس داخل الواجهة. يمكن اختيار اسم النموذج عبر secret باسم `AI_MODEL` (الافتراضي `gpt-4o-mini`) وقاعدة API عبر `AI_API_BASE_URL` إن كان مزودك OpenAI-compatible. بدون هذا الإعداد يظهر رد استلام ثابت ويوجه العميل إلى مراجعة المؤسس.

## حدود هذه النسخة

- موقع العميل ووجهته تُكتب كنص وصفي. لا يُعرض تتبع GPS حي ولا خرائط ملاحية؛ يلزم إعداد مزود خرائط وموافقته قبل تفعيل ذلك.
- لا توجد بوابة دفع إلكترونية، وهذا يطابق طلب الدفع النقدي.
- إشعارات الحالة حالياً داخل التطبيق وعبر الطلبات؛ إرسال SMS أو WhatsApp يحتاج موفراً ومفاتيح إعداد آمنة.
- تشغيل ملف SQL وتهيئة GitHub Pages خطوات تُجرى داخل حسابي Supabase وGitHub الخاصين بك. الملفات جاهزة لذلك، لكن لا أدّعي أنني نشرت إلى حسابك من دون صلاحية ومستودع محدد.
